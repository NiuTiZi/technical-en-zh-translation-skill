# 网络安全领域词库

适用于安全公告、检测规则、身份安全、事件响应与攻防报告。保留 CVE、检测规则字段、命令和日志原文。

| English term | 建议中文译法 | 适用语境/定义 | 备注 |
| --- | --- | --- | --- |
| vulnerability | 漏洞 | 可被利用的安全弱点 | 普通产品缺陷未必是漏洞 |
| exploit | 利用；漏洞利用 | 借助漏洞达到攻击目标的行为 | 作为代码/工具名称时保留原样 |
| proof of concept (PoC) | 概念验证（PoC） | 展示技术可行性的样例 | 安全 PoC 不必然是完整攻击工具 |
| attack surface | 攻击面 | 可供攻击者接触或利用的入口集合 | 不等于单个漏洞 |
| threat actor | 威胁行为者 | 实施或可能实施恶意活动的主体 | 不擅自推定身份或归属 |
| indicator of compromise (IoC) | 失陷指标（IoC） | 提示系统可能受侵害的可观察痕迹 | 具体哈希、域名等保持原样 |
| detection rule | 检测规则 | 用于识别特定行为或事件的规则 | 规则语法与字段不可改 |
| payload | 攻击载荷 | 攻击链中的恶意代码或数据 | 一般协议载荷仍按上下文译 |
| prompt injection | 提示词注入 | 恶意内容试图改变模型或 Agent 的指令遵循行为 | 与普通提示词区分 |
| lateral movement | 横向移动 | 攻击者在环境中转向其他主机或账户 | 不等于初始访问 |
| privilege escalation | 权限提升 | 获得高于当前权限的能力 | 与授权配置变更区分 |
| persistence | 持久化 | 攻击者维持访问能力的技术或阶段 | 普通数据持久化不适用 |
| exfiltration | 数据外传 | 未授权地将数据转移出受控环境 | 不等于普通数据导出 |
| credential stuffing | 凭证填充 | 使用泄露的用户名/密码对批量尝试登录 | 不等于暴力破解所有形式 |
| phishing | 网络钓鱼 | 诱骗用户披露信息或执行操作 | 可按上下文译为“钓鱼邮件”等 |
| false positive | 误报 | 检测结果错误地标记为有风险 | 与 false negative（漏报）区分 |
| false negative | 漏报 | 检测未发现实际存在的风险 | 与 false positive（误报）区分 |
| containment | 遏制；隔离控制 | 事件响应中限制影响扩大的措施 | 具体措施如隔离主机应明确 |
